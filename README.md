# CareerLaunch Platform

Welcome to **CareerLaunch**, a platform designed to help students build professional CVs, discover job opportunities, and apply directly to companies. This project is aimed at empowering students at KFUPM and other universities by providing a seamless career development experience.

## Features

🚀 **Key Features**:
- **CV Builder Tool**: An intuitive interface guiding students to create and customize their CVs with embedded tips and best practices.
- **Customizable Templates**: A variety of CV templates tailored to different majors, career paths, and personal preferences.
- **CV Repository**: A secure database for storing student CVs, accessible to employers with advanced filtering options.
- **Advanced Search & Filtering**: Employers can search for candidates based on criteria like graduation year, major, and GPA.
- **Export Functionality**: Export CVs in multiple formats (PDF, Word) for easy sharing.
- **Notification System**: Alerts students about job opportunities or interest from employers.
- **Interview Feature**: Employers can request and schedule interviews with students.
